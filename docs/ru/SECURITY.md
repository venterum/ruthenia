# Политика безопасности

> [English version here!](../SECURITY.md)

## Как сообщить об уязвимости

**Используйте GitHub Security Advisories** (вкладка Security → Report a vulnerability в этом репозитории).  
Так отчёт останется приватным до выхода исправления.

**Пожалуйста, не открывайте публичный issue** до исправления.

---

## Сроки реакции

- **Подтверждение получения** — в течение 7 дней
- **Оценка серьёзности и план исправления** — в течение 14 дней
- **Публичное раскрытие** — после релиза фикса, по согласованию с автором отчёта (при желании — с указанием авторства)

---
