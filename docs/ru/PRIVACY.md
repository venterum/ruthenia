# Политика приватности

> [English version here!](../PRIVACY.md)

В двух словах, **Ruthenia Store не собирает персональные данные, не использует аналитику и не делает сетевых запросов, кроме API каталога RuStore (и загрузки официальных сертификатов Минцифры при ручном обновлении сертификатов в настройках).** Любая обработка происходит исключительно локально.

---

## Разрешения

| Разрешение | Зачем |
|------------|-------|
| `INTERNET` | Единственный сетевой доступ; только к хостам, описанным ниже |
| `POST_NOTIFICATIONS` | Одно групповое уведомление «есть обновления» (Android 13+); запрашивается только при включении фоновых проверок |
| `REQUEST_INSTALL_PACKAGES` | Установка скачанных APK через системный `PackageInstaller` |
| `QUERY_ALL_PACKAGES` | Чтение списка установленных приложений **локально** (никуда не отправляется) |
| `ACCESS_NETWORK_STATE` | Проверка сети в WorkManager (Wi-Fi / доступность) |
| `WAKE_LOCK` | Удержание CPU во время проверки обновлений |

---

## Сетевые хосты

| Хост | Назначение | TLS | Пиннинг |
|------|------------|-----|---------|
| `backapi.rustore.ru` | Поиск, лента, инфо о приложении, ссылки на скачивание | Системное | ✅ |
| `api.rustore.ru` | Nonce для подписи сессии | Системное | ✅ |
| `static-m.rustore.ru` | Скачивание APK/ZIP, иконки | **Russian Trusted Root/Sub CA** | ✅ |
| `static.rustore.ru` | Возможный CDN иконок | Системное | ✅ |
| `gu-st.ru` | Официальные сертификаты Russian Trusted CA (Минцифры); только при ручном обновлении сертификатов | Системное (GlobalSign) | — |

- Все запросы используют **только HTTPS** (`usesCleartextTraffic=false`)
- В APK встроены Russian Trusted CA, используются только для доступа к `static-m.rustore.ru` по HTTPS.
- Запрос отклоняется, если цепочка не совпала с известными пинами
- Пины вшиты в APK. Их можно обновить вручную: Настройки → «Безопасность» → «Сертификаты RuStore». Приложение сверяет живые цепочки хостов RuStore и официальные сертификаты Минцифры (`gu-st.ru`). Автоматических обращений нет.

## Что передаётся в запросах

| Поле | Значение |
|------|----------|
| `deviceId` | 8 случайных байт + хэш модели; генерируется при каждом запуске; **не сохраняется**, не связан с рекламным ID |
| `deviceManufacturerName`, `deviceModelName`, `deviceModel` | Константы (`Google Pixel 8 Pro`) — одинаковы у всех |
| `firmwareVer`, `androidSdkVer`, `firmwareLang` | Константы |
| `ruStoreVerCode`, `deviceType` | Константы |
| `User-Agent` | `RuStore/<ver> (Android …)` |
| `X-Client-Signature` | `base64(HMAC-SHA256(ключ, nonce ‖ certSha256))` — считается локально |
| Тело `download-link` | `appId`, `firstInstall`, `supportedAbis`, `sdkVersion`, `screenDensity` — реальный профиль для корректных split-APK |

---

## Чего приложение НЕ делает

- ❌ Не шлёт данные на хосты, кроме перечисленных выше
- ❌ Не персонализирует рекомендации
- ❌ Не устанавливает APK без вашего явного согласия
- ❌ Не собирает статистику использования и аналитику
- ❌ Не запрашивает никакие лишние разрешения

---

## Использование локального хранилища

| Данные | Где | Срок |
|--------|-----|------|
| Кэш приложений (название, иконка, описание, рейтинг, загрузки, версия) | Room `catalog_apps` | До очистки кэша |
| Секции домашней ленты | Room `home_entries` | До очистки кэша |
| Список установленных + версии | Room `installed_apps` | До удаления из списка |
| Скрытые обновления (package + версия) | DataStore `ignored_updates` | До сброса настроек |
| Настройки (тема, динамика, интервал, Wi-Fi, диагностика) | DataStore | Бессрочно, только локально |
| Сид профиля устройства (случайный install ID для печати в шапке) | DataStore `local_identity_seed` | До очистки данных приложения; не в бэкапе |
| Скачанные APK | `cacheDir/apk/<package>` | Удаляются после установки |

## Логирование

- Сторонних крашлитиков и аналитики нет и не будет
- Постоянного логирования запросов нет
- Опциональная локальная диагностика: **выкл. по умолчанию**, остаётся на устройстве, никогда никуда не отправляется

## Не верите написанному выше?

И правильно делаете! Ниже простой гайд по тому, как можно самостоятельно всё проверить.

1. Поставьте [mitmproxy](https://mitmproxy.org/) и направьте трафик устройства через него
2. Установите mitmproxy CA **только для проверки** (приложение ему не доверяет — пиннинг + кастомный TrustManager)
3. Убедитесь, что хосты совпадают с таблицей выше

Проверка разрешений и содержимого APK:

```bash
aapt2 dump badging app/build/outputs/apk/release/app-release*.apk
unzip -l app/build/outputs/apk/release/app-release*.apk | grep -E "res/.*\.cer"
```
