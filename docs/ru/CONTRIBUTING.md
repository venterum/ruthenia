# Участие в разработке

> [English version here!](../CONTRIBUTING.md)

Спасибо за интерес к проекту! Здесь коротко о том, как можно помочь проекту вашим кодом.

---

## Сборка и тесты

```bash
# Debug APK
./gradlew :app:assembleDebug

# Release APK
./gradlew :app:assembleRelease

# Юнит-тесты (без сети)
./gradlew testDebugUnitTest

# Lint
./gradlew :app:lintDebug
```

**Требуется:** JDK 17, Android SDK 37

---

## Стиль кода

- Kotlin, 4 пробела, trailing commas
- Каждый файл начинается с заголовка GPL-3.0 (скопируйте из любого соседнего)
- Все пользовательские строки — только в `strings.xml` + `values-en/strings.xml`
- Числовые подписи делайте через `plurals` (не склеивание строк)
- Не злоупотребляйте комментариями! Помните, что они объясняют «почему так», а не «что это»
- Основной язык документации, кода и комментариев — это английский, при возможности документация дублируется на русском (подобно этому файлу).

## Архитектура (модули)

| Модуль | Ответственность |
|--------|-----------------|
| `:core:security` | Доверие к сертификатам, SPKI-пины, ручное обновление сертификатов |
| `:core:network` | API RuStore, DTO, подпись сессии |
| `:core:data` | Room, DataStore, репозитории, бэкап |
| `:core:installer` | Загрузка APK, проверка подписи/размера, PackageInstaller, Shizuku |
| `:core:updates` | WorkManager: проверка обновлений, фоновые загрузки и менеджер загрузок |
| `:core:designsystem` | Тема, токены, компоненты Material 3 Expressive |
| `:feature:*` | Экраны и ViewModel |
| `:macrobenchmark` | Baseline/startup профили, замеры производительности |
| `:app` | Точка входа, навигация, Hilt-граф |

Зависимости **всегда** направлены внутрь (`feature → core`), но никогда не наоборот.

## Правила приватности

- Новый сетевой хост или изменение данных в сети → правка `PRIVACY.md` в том же PR
- Любые предложения по включению аналитики, крашлитики в проект не рассматриваются
- Новые разрешения только с обоснованием в манифесте и в PRIVACY.md

---

## Pull Requests

- Одна логическая правка на один PR; опишите, что и зачем изменилось
- Приложите, как проверяли: команды и, если менялся UI — скриншоты до/после
- Не поднимайте версии зависимостей попутно с какими-либо изменениями, для этого лучше сделать отдельный PR
- Все тесты должны проходить (`testDebugUnitTest`, `lintDebug`)
